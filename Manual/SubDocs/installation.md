# Installation

The Python code and the model/project data live in separate locations, typically on a shared network drive, so that one copy of Bryan's code serves many dam catchments. The main Python script is ```Main.py```. However, Bryan is set up in a way that you don't need to run it using an IDE; it is run using a batch file. You have a choice of running it from the shared drive or copying the ```Bryan``` folder to your local drive and running it from there, whichever works best for you. A Python 3 installation is needed, with the following packages: json, scipy, numpy, and pandas. It is good practice to [set up a virtual environment](virtual_env_setup.md).

The model itself, as in the URBS/RORB model and all associated files for the study catchment, will live in an entirely separate location. It is recommended that you build and run the model on your local drive and back up to the shared drive regularly, noting that a strict folder and file structure should be adhered to -- see an existing model for an example. Creating a batch file to back up the model using [robocopy](https://learn.microsoft.com/en-us/windows-server/administration/windows-commands/robocopy) is a good option for this, as long as there is no one else working on the same model as you at the same time. If multiple people are working on a model, a version control system (e.g. TortoiseSVN or Git) is another option -- check with your organisation's IT support for how it's provisioned.
